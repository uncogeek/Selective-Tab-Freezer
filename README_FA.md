# Selective Tab Freezer

[English](README.MD)

این افزونه فقط تب‌هایی را از حافظه خارج می‌کند که URL آن‌ها شامل یکی از URLها یا عبارت‌های ذخیره‌شده باشد. تب بسته نمی‌شود و با فعال‌کردن دوباره Reload خواهد شد.

![Screenshot](https://github.com/uncogeek/Selective-Tab-Freezer/blob/main/screenshot/screenshot-fa1.png?raw=true)

با این افزونه رم مرورگرتون واقعاً آزاد میشه، دقیقاً مثل کاری که Memory Saver خود Chrome انجام میده؛ با این تفاوت که شما تعیین می‌کنید کدوم تب‌ها فریز بشن و کدوم‌ها همیشه فعال بمونن.

وقتی که تب های زیادی رو از Tradingview در مرورگر کروم باز کردید و خطای Connection limit روبرو میشید، یا تعداد تب های باز شده زیاده و نیاز دارید که بعضی از تب ها موقتا freeze بشن ولی بسته نشن،
این افزونه این کار رو برای شما مدیریت میکنه!

## نصب یا به‌روزرسانی
1. فایل ZIP را Extract کنید.
2. در Chrome آدرس `chrome://extensions` را باز کنید.
3. گزینه **Developer mode** را روشن کنید.
4. برای نصب تازه، روی **Load unpacked** بزنید و پوشه `Selective-Tab-Freezer` را انتخاب کنید.
5. برای به‌روزرسانی نسخه قبلی، محتویات پوشه قبلی را با نسخه جدید جایگزین و سپس دکمه **Reload** افزونه را بزنید.
تنظیمات نسخه 1.0 به‌صورت خودکار به جدول جدید منتقل می‌شود.

## Popup
کلیک روی آیکن دیگر فوراً Freeze نمی‌کند. Popup سه امکان دارد:
- افزودن URL کامل تب فعلی همراه با توضیح اختیاری
- اجرای Freeze برای تب‌های موجود در فهرست
- بازکردن صفحه مدیریت و تنظیمات

## مدیریت فهرست
هر URL یا عبارتی که اضافه می‌کنید توی یک جدول ساده می‌شینه، با توضیح اختیاری کنارش تا بعداً یادتون بیاد چرا اضافه‌ش کردید. هر وقت خواستید می‌تونید ویرایشش کنید یا با یک کلیک حذفش کنید.

می‌خواید چندتا آدرس با هم اضافه کنید؟ دکمه **افزودن از لیست** رو بزنید، توی Textarea باز شده هر خط رو یک آدرس بنویسید، تمام. مواردی که تکراری باشن خودکار نادیده گرفته می‌شن، نگران Duplicate شدن نباشید.

جست‌وجو هم زنده‌ست؛ همین‌طور که تایپ می‌کنید بین URLها و توضیحات فیلتر می‌شه، بدون هیچ Reload یا تاخیری.

برای پشتیبان‌گیری یا انتقال تنظیمات، می‌تونید فهرست رو به‌صورت JSON خروجی بگیرید (همراه با توضیحات) یا از فایل JSON و TXT وارد کنید؛ موارد وارد شده با فهرست فعلی‌تون Merge می‌شن، نه جایگزین.

## زبان
زبان پیش‌فرض فارسی است. از تنظیمات می‌توان English را انتخاب کرد؛ کل Popup و تنظیمات LTR می‌شوند. URLها در هر دو زبان همیشه LTR باقی می‌مانند.
فایل راهنما با نام `PUT-FONTS-HERE.txt` از قبل داخل همین پوشه قرار دارد. اگر فونت‌ها موجود نباشند، رابط موقتاً از Tahoma یا Arial استفاده می‌کند.
پس از افزودن فونت‌ها، در صفحه `chrome://extensions` دکمه **Reload** افزونه را بزنید.

## محدودیت Chrome
Chrome اجازه Discard کردن تب فعال را نمی‌دهد. اگر یک تب هدف فعال است، ابتدا به تب دیگری بروید و سپس دستور Freeze را از Popup اجرا کنید.

## حریم خصوصی
افزونه هیچ Analytics، اتصال شبکه یا کد خارجی ندارد. فهرست و زبان فقط در Storage محلی همان پروفایل Chrome ذخیره می‌شوند.
